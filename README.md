# 会津大学 入学者データアトラス

2016〜2026年度の入学者数を都道府県別に探索する、静的なデータ分析Webアプリです。CSVとPlotly.jsを使い、バックエンドは不要です。

## 起動

```bash
npm install
npm run dev
```

ターミナルに表示されたURLをブラウザで開いてください。

## 本番ビルド

```bash
npm run build
npm run preview
```

## Vercel公開

- Framework Preset: `Vite`
- Root Directory: このフォルダ `aizu-admissions-web`（このフォルダをリポジトリ直下に置いた場合）
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

このフォルダだけをリポジトリのルートにした場合、Root Directoryは空欄（`./`）です。

## データ

`public/enrollments.csv` をサイト初期表示のデータに使用します。画面上の「CSVを読み込む」でも差し替えられます（ブラウザ内のみ、サーバー送信なし）。

入力CSVは以下を含む必要があります。

- `都道府県`、`2016年度` のような年度列（2年度以上）
- 47都道府県の各行と `その他` の行
- `合計` 行は任意。存在する場合は年度別の合計を内訳と照合
- `11年合計` 列は参考情報。年度別人数から再計算

注：添付CSVの「合計」行の `11年合計` は3,958と記載されていますが、各年度合計の和は2,731です。画面では再計算値を使用します。

## 指標と注意点

- 11年度の新入学者が対象（編入学を除く）
- 各都道府県の構成比の分母には「その他」も含みます
- HHIおよびShannon実効都道府県数では「その他」を除き、47都道府県で再正規化
- Jensen–Shannon距離は48区分を使用、底2の対数による距離
- トリーマップに累計0人の県は描画されませんが、それ以外の図表には残ります
- タイル図は模式配置であり、実際の都道府県地図ではありません
- 実行時にGoogle Fontsのダウンロードができない場合はシステムフォントにフォールバック

## 主な分析

年間入学者推移、福島県比率、トリーマップ、都道府県タイル図、県外ランキング、初期・直近の変化、地方別積み上げ、全県ヒートマップ、Shannon実効県数、HHI、Jensen–Shannon距離、複数県比較、都道府県別評価指標、CSV出力。
