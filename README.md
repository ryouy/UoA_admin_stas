# 会津大学 入学者データ

都道府県別入学者数を可視化する Vite + Plotly.js サイトです。

## ローカルで起動

Node.js と npm をインストールしてから、次のコマンドを実行します。

```bash
npm install
npm run dev
```

Vite が表示するローカルURLをブラウザで開いてください。

## ビルドとプレビュー

```bash
npm run build
npm run preview
```

`npm run build` は配布用ファイルを `dist/` に生成し、`npm run preview` はビルド結果をローカルで確認するためのコマンドです。

## データについて

可視化に使う CSV は `public/enrollments.csv` です。

- 各行は都道府県を表します。
- `2016年度` から `2026年度` まで、年度ごとの人数が記録されています。
- `11年合計` 列には11年度分の合計人数が入っています。
- 文字コードは UTF-8 で保存してください。CSVの列名を変える場合は、読み込み側のコードも確認してください。

データを更新する際は、年度ごとの値と `11年合計` の整合性を確認してからコミットしてください。
